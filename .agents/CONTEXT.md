## 快速切换器

DSH Web 的会话切换面板。它把 DSH 已经算好的会话、工作区、快捷键命令、会话消息与工作区文件投影成可搜索的行；在工作区里新建会话的行为也交给 DSH 自己的新会话入口，文件内容与文件预览则交给右侧栏。`?` 模式另外持有当前会话的侧问记录，并在宿主半区调用模型生成答案。打开主面板时，主区域不再显示会话，因此「当前会话」不等于「上个会话」。七种列表各是一个模块，面板外壳只认识模块接口，不认识任何具体模式。设置页可以在运行中开关任意已注册模块；模块声明的入口让本体自动注册一条直达该模式的命令。

### Language

统一会话状态：
DSH 维护的一份逐会话状态 Map，包含运行中、待处理交互与完成未读；侧栏与切换器都从同一个标准 Slot 钩子读取。
_Avoid_: 会话状态副本、本地状态

待处理交互：
会话正在等待用户动作的状态，目前包括审批、计划审阅与回答。侧栏只把这三种投影成警告点。
_Avoid_: 阻塞、挂起

完成未读：
会话结束运行时并未被主视图保留，DSH 为它记下的完成提醒，侧栏用绿点提示。它按保留而非按当前可见性判定，所以主面板打开时，被保留会话的结束不会变成完成未读。
_Avoid_: 未读消息、新消息

主面板：
左侧栏面板列表打开的整页界面，例如插件和自动化任务。主面板选中时，主区域让位给它，此时不存在当前会话。切换器列出它们并用布局服务打开，因此不拥有主面板本身的任何状态。
_Avoid_: 弹层、对话框、浮层、页面

主面板模式：
输入框以 `#` 开头、列表只显示主面板匹配器认领时的状态，按本地化标题与注册 id 做整串模糊匹配；每行在标题下方列出可搜索的注册 id，注册 id 与标题相同时省略这一行。
_Avoid_: 面板页、主面板搜索

主面板行：
主面板模式里的一行，对应 DSH 侧栏面板列表的一个注册项。主区域正在显示的那个主面板在它自己的行上标「当前」，与会话行的「当前」互斥。
_Avoid_: 页面行、入口行

主视图保留：
某个会话仍被主视图挂载的引用计数。保留不等于正在显示；打开主面板后，原会话通常仍被保留。
_Avoid_: 选中会话、打开会话

当前会话：
主区域正在显示的会话。没有选中任何主面板，且会话仍被主视图保留时，切换器才给这一行显示「当前」。
_Avoid_: 活跃会话、焦点会话

上个会话：
当前会话之前最近访问过的会话；停在主面板时没有当前会话，此时就是主视图保留的那个会话。切换器把它固定在第一行，并在行上标「上个会话」，与「当前」互斥。
_Avoid_: 上次会话、当前会话、上次打开的会话

访问时间：
插件记录的、用户上次在主区域看到某个会话的时间，存在浏览器本地。没有记录的时候，会话的更新时间代替它参与排序与时间标签；待处理组在默认顺序下另行处理没记录的行，见待处理排序。
_Avoid_: 最近活动时间、最后消息时间

待处理排序：
待处理组内的行序。默认最久未访问优先：没打开过的排最前，彼此按会话更新时间从旧到新；打开过的按访问时间从旧到新往后沉，所以打开一条处理不了的会话只会让它往后走。设置可以切回最近访问优先，即列表其他状态组一直使用的规则。
_Avoid_: 正序、倒序、待处理优先级

状态点：
DSH 官方 StateDot 组件画出的状态标记，ongoing 是旋转环，done 是绿点，warning 是警告点。
_Avoid_: 指示灯、圆点

会话 id:
DSH 给每个会话的唯一标识，形如 `session-<UUID>`，共 44 字符；侧栏右键菜单把它整串复制出来。切换器不拿它当标题，只用它定位会话。
_Avoid_: 特征码、会话编号、会话码

会话短码：
会话 id 去掉 `session-` 前缀与连字符后的前 8 位，显示在会话行时间后面，用来核对按 id 找到的是哪一个会话。规范化后不足 4 位的自定义 id 不显示短码。
_Avoid_: 编号、序号、特征码、短 ID

工作区：
DSH 按路径把会话聚合成的分组，带标题、路径与会话 id 列表。切换器只读取它，从不创建或修改。
_Avoid_: 项目、目录、文件夹

工作区模式：
输入框以 + 开头、但还没有形成作用域词时切换器所处的状态，列表只显示工作区，按整串模糊匹配过滤。
_Avoid_: 工作区页、工作区搜索

作用域词：
输入框里以 + 开头、在某个完整工作区标题后面紧跟一个空格的文本，用来把列表限定到那个工作区。
_Avoid_: 前缀、标签

作用域：
切换器已经被作用域词限定到某个工作区时的列表状态，只列出该工作区的会话。
_Avoid_: 二级目录、工作区详情

新建会话行：
作用域列表顶部固定的一行，不参与关键词过滤，选中即在该工作区新建会话。
_Avoid_: 加号行、创建按钮

新建会话：
在指定工作区里打开一个空白会话的动作，由 DSH 的 startSession 完成，并沿用它的空白草稿复用规则。
_Avoid_: 创建对话、新开聊天

匹配器：
模块判断一个查询是否由自己认领的函数，返回自己的状态或 null；本体按优先级取第一个认领者，面板只负责选中、键盘与动作调用。
_Avoid_: 路由、处理器、模式

模式别名：
匹配器可选的 `mode` 字段，默认等于匹配器 id；同一模式的多种写法各用一个匹配器，却可以发布同一个模式别名，模式命令与公开状态因此仍把它们当成一个模式。
_Avoid_: 模式 id、匹配器别名

整串模糊匹配：
把查询当成一条字符序列，忽略大小写与空白，字符按顺序出现即命中；标题或显示名优先，只有它不命中时才匹配工作区标题、路径、命令别名、主面板注册 id 或问答回复的题面。会话 id 是这条规则的唯一例外，按前缀命中，见 id 前缀命中。
_Avoid_: 分词搜索、逐词命中、全文搜索

id 前缀命中：
整串模糊匹配之外的唯一例外：查询规范化后至少 4 位、且是会话 id 开头时才按 id 命中；它仍算次要字段，标题命中排在它前面，短码也不高亮。
_Avoid_: id 模糊搜索、id 包含搜索、唯一码搜索

应用命令：
DSH 客户端快捷键注册表里的可编辑命令，带显示名、别名、当前生效按键与 resolve 动作；「编辑快捷键」页与命令列表读同一份 catalog。
_Avoid_: 快捷键、动作、快捷方式

命令模式：
输入框以 `>` 开头、列表只显示应用命令匹配器认领时的状态，按显示名与别名做整串模糊匹配；每行在显示名下方列出可搜索的英文别名。
_Avoid_: 命令页、命令搜索

最近命令：
本插件在浏览器 localStorage 里按执行顺序记录的命令 id 列表，空查询时置顶，其余命令按显示名排序。
_Avoid_: 常用命令、历史记录

命令执行：
把选中的应用命令交给它自己的 resolve 结果运行；允许运行的前提是该命令在无弹层上下文里返回 handled。执行使用打开面板前的焦点作为 target，并把面板当作已经关闭。
_Avoid_: 调用命令、触发快捷键

输入历史：
当前会话里用户已经发送的提示词、插话与 `ask_user_question` 的回答，按发送时间倒序展示；回答按题拆行，题面只参与搜索；数据来自会话已加载的消息窗口，不另存一份本地记录，选中后可整段写回输入框。
_Avoid_: 聊天记录、消息历史

历史模式：
输入框以 `!` 开头时切换器所处的状态，列表只显示当前会话的输入历史；应用命令打开面板时直接用 `!` 播种查询。
_Avoid_: 历史页、历史搜索

草稿行：
历史模式顶部固定的一行，显示面板打开那一刻输入框里的文本；选中它把该文本写回输入框，草稿为空时不显示。
_Avoid_: 当前输入、草稿历史

加载更早行：
历史模式底部的一行动作，按一次让会话控制器补一页更早的消息；补进来的输入累计最多 200 条。
_Avoid_: 分页、更多按钮

问答回复：
DSH 把 `ask_user_question` 的已答批次投影成 `question-reply` 聊天节点，带题面与回答；它不是 `user/message`，所以历史按回答行单独投影。迟到回答与阻塞回答共用这个节点。
_Avoid_: 答案气泡、提问记录

回答行：
历史里 `kind` 为 `answer` 的一行，标题是用户当时的回答（选项标签或自定义文本），右侧标「回答」；回车把回答写回输入框，题面只进次要搜索字段。
_Avoid_: 问答行、题面行

悬停选中：
指针真实移动之后，选中跟随指针所在行的行为；指针静止时浏览器补发的悬停事件不改变选中。
_Avoid_: 鼠标高亮、划过选中

指针基线：
用来判断指针是否真的动过的最近一次真实指针位置，由插件在页面载入后持续记录；面板打开或列表重排时浏览器补发的事件坐标与它相同，因此被当作未移动。
_Avoid_: 鼠标位置、光标坐标

直达提示：
列表前九行右侧显示的 Alt 加数字标签，提醒这一行可以直接用 Alt+数字执行。它按当前可见顺序生成，第 10 行及以后不显示。
_Avoid_: 行号、序号、编号

数字直达：
按住 Alt 再按 1 到 9，直接执行当前列表对应行的行为，等同对该行按 Enter。Shift 不改变动作，小键盘数字与带 Ctrl 或 Meta 的组合不参与。
_Avoid_: 数字快捷键、快速选择、Alt 选择

文件模式：
输入框以 @ 开头、列表只显示当前会话工作目录里文件与目录匹配器认领时的状态；候选由 DSH 的 Host 按会话的工作目录检索，插件不建自己的索引。界面文案沿用「工作区」，实际检索的目录可能被会话工具改到工作区路径以外。
_Avoid_: 文件页、文件搜索模式、附件模式

文件候选：
Host 文件检索返回的一条结果，带相对会话工作目录的路径与类型（文件或目录）；路径用 / 分隔，不解析 . 与 ..。
_Avoid_: 文件项、结果行、文件对象

目录行：
文件模式里类型为目录的候选行。Enter 把该目录的路径加一个 / 补进输入框，列表接着列出这个目录，和会话输入框 @ 菜单的钻取一致。
_Avoid_: 文件夹行、层级行

侧栏预览：
DSH 右侧栏里的文件文档页，按文件地址读取并渲染文件；菜单关闭后用户看到的文件内容属于它，不属于切换器。
_Avoid_: 文件查看器、预览弹层、编辑器

文件地址：
把会话 id 与相对工作目录的路径编码成的 `dsh-resource://file/session/<会话 id>/<路径>`。它同时是读取权限与内容身份，右侧栏据此确定用哪个会话的工作目录解析路径。
_Avoid_: 文件路径、绝对路径、资源链接

预览焦点：
打开文件后把键盘焦点交给右侧栏当前面板的行为。文件行的 Shift+Enter 触发它；Enter 相反，把焦点还给打开面板前的控件。
_Avoid_: 抢焦点、自动聚焦

### 侧问

侧问与它的界面状态是切换器里唯一会调用模型的一组概念，其余列表都只做投影与导航。

侧问：
就当前会话问一个不进入主对话、不写会话日志、不落盘的一次性问答；请求携带模型可见历史、工具轨迹与运行中的现场。
_Avoid_: 旁问、副问、btw

侧问快照：
发给侧问模型的消息集合，由主会话的模型可见历史加上运行中的现场块组成，不是整份事件日志。
_Avoid_: 完整上下文、全量会话

工具轨迹：
侧问快照里把 assistant 的 tool-call 与 tool-result 渲染成的带工具名文本，保留参数、结果与「尚无结果」状态。
_Avoid_: 工具日志、工具历史

现场块：
主会话运行中时追加在侧问快照末尾的只读块，含当前轮与步骤、正在流式生成的正文与推理，以及仍在生成工具调用的状态。
_Avoid_: 实时上下文、运行状态

附件携带：
侧问是否把图片与文件块原样发给模型；默认携带，设置页可关，关闭后只留占位。
_Avoid_: 附件开关、图片发送

侧问模型：
侧问固定使用的 provider 与模型；默认跟随当前会话的模型，设置页可改，只影响侧问，不回写主对话的选择。
_Avoid_: 旁问模型、副模型、备用模型

推理等级：
模型自带的思考档位；侧问默认用该模型支持的最低档，模型不支持所选档位时向下取最近的可用档，没有推理能力的模型不传档位。
_Avoid_: think 程度、思考程度、思考等级

触发符：
侧问模式用来认领查询的字符，共四个码点，NFKC 规范形都等于 `?`：`?`、`？`、`﹖`、`︖`。出现在开头或末尾都算，与界面语言无关；后缀位置只剥掉一个，多打的留在问题正文里。发问后锁定的输入行保留用户打的那一个与它所在的一端。
_Avoid_: 前缀、问号键、模式标记

后缀触发：
触发符出现在查询末尾时认领侧问的方式。只有没有任何前缀匹配器认领时才生效，因此 `@foo?` 仍是文件搜索；判定只看最后一个字符，之后再有一个空格就不算。它剥掉一个触发符，余下文本是问题；末尾不再是触发符时立刻退出侧问，没有隐藏的粘性状态。
_Avoid_: 后缀模式、尾部触发、粘性模式

侧问模式：
输入框以一个触发符开头或结尾时切换器所处的状态，去掉触发符后的文本整体是待发出的问题，不是过滤词。
_Avoid_: 问询模式、侧问面板、提问页

发问行：
侧问模式下去掉触发符后已有文本时列表首行，回车把该文本作为一条新侧问发出。
_Avoid_: 提交行、发送行

侧问记录：
当前会话某次侧问的问题、答案、背景、发问时选定的模型与档位、实际生效的模型与推理等级、用量，只存在内存里，刷新即丢。
_Avoid_: 侧问历史、问答记录

侧问详情：
复用列表区展示一条侧问记录答案的视图，输入行锁定为该记录的问题，可复制、重新生成、分叉与回到输入框。
_Avoid_: 侧问卡片、答案页

答案渲染：
侧问详情把答案画成 DOM 的那一层，直接复用 DSH 会话面板的 MarkdownText，链接、表格、公式与代码高亮因此与会话面板同形；插件只提供代码块与脚注的文案标签，不自己解析 Markdown，也不接管链接点击。
_Avoid_: markdown 渲染器、自写渲染器、答案样式

回到输入框：
侧问详情里的 `i` 手势，取 vim 的插入语义，退出详情、回到列表并把焦点还给输入框，问题文本保留；焦点落在锁定的问题框里也生效。
_Avoid_: 返回键、Backspace, Esc

侧问背景：
发问时从待处理交互上摘取的只读文字，随记录保存，用来向模型解释审批命令或提问正文。
_Avoid_: 审批上下文、引用块、附件

已中止：
用户按下停止或关闭面板时被打断的侧问记录状态，已收到的部分答案仍然保留。
_Avoid_: 中断、取消

### 架构

本体：
只认识模块接口的一层代码，负责注册中心、面板外壳、设置、文案与宿主装配，不认识任何具体模式或领域投影。
_Avoid_: 核心、框架、引擎

模块：
一个垂直特性交给本体的完整声明，包含入口、依赖、说明、匹配器、挂载面、设置、文案、命令、槽与内容视图。
_Avoid_: 插件、路由、模式包

挂载：
每次打开面板时为一个模块创建运行实例的过程，关闭面板即释放本次挂载。
_Avoid_: 初始化、实例化

静态能力包：
模块声明函数在加载时收到的能力，包含模块 id、文案、设置、面板控制器、共享 store、DSH 服务、可选服务取用、effect 与日志，跨面板挂载稳定。
_Avoid_: 上下文、ctx、依赖

面板上下文：
每次打开面板时传给模块的运行上下文，包含当前会话与主面板 id、待处理交互、当前时间与面板动作。
_Avoid_: 运行环境、会话上下文

视图渲染器：
模块按 kind 注册、用来替换列表区或底栏的 React 组件，本体按 kind 查表。
_Avoid_: 详情组件、自定义视图、插槽

视图文案：
内容视图与底栏渲染器收到的翻译函数，按注册该视图 kind 的模块查找，缺键回退本体文案。
_Avoid_: 模块翻译、全局文案

设置分组路径：
模块设置的寻址方式，形如 `[模块, 分组?, 字段]`，分组可省略，字段 id 在模块内唯一。
_Avoid_: 设置键、配置路径、命名空间

共享 store:
模块之间按名字共享的可订阅快照，未发布时读出 null；它让一个模块拥有的数据被另一个模块读取，而不用互相 import。
_Avoid_: 全局变量、事件总线、服务单例

公开服务：
本体提供给其他客户端插件的 `quickSwitcher` 服务，带 apiVersion、模块注册与面板控制。
_Avoid_: 插件 API、扩展点、外部接口

宿主模块：
只在宿主半区装配、贡献 webServer 路由与事件订阅的模块。
_Avoid_: 服务端模块、后端插件

设置页：
本插件注入到宿主设置对话框的整块内容，与左栏的一个导航项一一对应；对话框外壳、左栏与页面外边距由宿主提供，设置页只排版自己的分区与行。
_Avoid_: 设置界面、设置面板、配置页

模块开关：
本体持有、按浏览器保存的模块启停状态；关闭只停运行贡献，保留文案与设置声明。
_Avoid_: 启用状态、禁用状态、模块配置

运行贡献：
模块在运行中实际参与的部分，包含命令、槽、内容视图与每次面板挂载。
_Avoid_: 动态贡献、副作用

声明贡献：
模块的文案与设置声明；模块关闭时仍保留，设置页据此继续显示它的标题、说明、开关与偏好。
_Avoid_: 静态贡献

模块入口：
模块声明的查询种子与模式显示名，本体据此自动注册一条模式命令，并把它列为默认模式的候选。
_Avoid_: 路由、前缀、触发词

模式命令：
由模块入口自动注册的应用命令，id 为 `quickSwitcher.mode.<模块>`，按下时打开、切换或关闭面板到该模式。
_Avoid_: 直达快捷键、快捷方式、路由命令

默认模式：
通用打开快捷键在没有显式种子时进入的模式，由设置页选择；未选择时取第一个带入口的模块。
_Avoid_: 默认页、首页

模块依赖：
一个模块声明的数据来源模块；设置页在来源被关闭时给出警告，但不自动联锁。
_Avoid_: 依赖注入、强依赖
