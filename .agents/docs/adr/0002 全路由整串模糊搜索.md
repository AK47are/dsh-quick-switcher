## 全路由整串模糊搜索

会话、工作区、命令、输入历史与主面板五种列表共用整串模糊搜索：查询忽略大小写与空白，字符按顺序出现即命中；标题或显示名优先，只有它不命中时才匹配次要字段并降权。这样同一个输入在不同列表里给出同一手感，也避免为命令列表单独维护第二套规则；主面板的标题是本地化标签，次要字段是注册 id。文件列表沿用 DSH 自己的排序，侧问列表不参与模糊过滤。

考虑过保留分词搜索、只给命令列表用模糊匹配，但那样命令框和会话框对同一个关键词的响应不同，用户需要记住两套规则。代价是多词查询不再要求每个词都命中，可能多出一些弱相关结果；命中分数决定顺序，弱结果只会排在后面。

空查询仍按各路由自己的基础顺序，模糊匹配只在有查询词时重新排序：会话按状态优先的顺序，见 ADR 0001 与 0015；工作区按最近会话活动，命令先按最近使用再按显示名，输入历史按发送时间倒序，主面板按侧栏注册顺序。
