## 命令面板接入快捷键

命令面板列的是 DSH 客户端快捷键注册表里的应用命令，而不是会话级斜杠命令。执行时从 `ctx.shortcuts.registry` 取到命令对象，用面板打开前的焦点构造 `{ target, region, modal: null, source: "menu" }` 调它的 `resolve`；只有返回 handled 才关闭面板并运行。

DSH 没有公开的按 id 执行入口，`registry` 是内部字段；另一条路是合成键盘事件，但绑定可以被用户改掉，而且命令可能在面板弹层下被区域策略拦住。斜杠命令虽然能通过 `commandUi.execute` 公开执行，但它按会话作用域绑定，面板打开时可能根本没有当前会话。接受内部结构带来的升级回归，换取命令列表与「编辑快捷键」完全同源。

考虑过的替代方案是给 DSH 上游加一个公开的 invoke；在当前版本不可行，等公开 API 出现后应该替换这里的内部访问。
