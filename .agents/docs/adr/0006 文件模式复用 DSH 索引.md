## 文件模式复用 DSH 索引

@ 文件模式不自己扫描工作区，也不自己渲染预览：搜索走 Host 的 fileReferences，打开走右侧栏的 sidebarRight.openResource 与 `dsh-resource://file/session/<会话 id>/<路径>` 地址。这样忽略规则、索引缓存、排序与预览渲染都跟会话输入框的 @ 菜单同源，插件只负责行、目录钻取与焦点。

代价是依赖 remote.fileReferences 与 sidebarRight 两个内部接口，并且要求主区域有当前会话。另一条路是用 workspaceFiles.list 逐层遍历再自建索引，但那样要自己处理忽略规则、大仓库性能与预览，等于复制 DSH 已有的能力。DSH 提供公开的搜索与打开入口后，应该替换这里的内部访问。
