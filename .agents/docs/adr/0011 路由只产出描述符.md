## 路由只产出描述符

状态: 已被 0016 取代

`src/routes/*` 不 import React. 需要渲染组件的视图返回 `content` 与 `footer` 描述符, 由 `src/panel/dialog.js` 按 `kind` 分派给 `src/panel/ask-detail.js`, 面板据此切换列表区与底部栏.

这样路由守住「输入投影成视图数据」这一层, `tests/ask.test.js` 用 node --test 直接导入, 不必把 react 加进 devDependencies; 面板也只需要认识描述符的 kind, 不需要知道详情内部.

代价是详情用到的每个新字段都要在描述符与组件之间多传一次, 且 kind 是面板里的一条手写分支. 出现第二种组件视图时, 这条分支要提升成注册表.
