## 问答回复成为历史行

`ask_user_question` 的回答不是 `user/message`，DSH 把它投影成 `question-reply` 聊天节点，带 `questions` 与 `answers`。历史原先把 `user` 与 `steering` 之外的东西全过滤掉，所以同一轮里只有开局提示词能进列表，用户答完问题后也看不到自己的回答。

现在历史按题拆行：回答是行标题，徽标「回答」，题面只进次要搜索字段；跳过题没有可写回的文本，不产行；相邻去重只适用于 `user` 与 `steering`，因为同一批里两道题都答「是」是两条真实回复。迟到回答与阻塞回答走同一个节点类型，因此一条规则覆盖两者。

代价是历史依赖 `dsh-client-ui-user-questions` 的节点名与 `questions`/`answers` 形状；DSH 改名或改形状时这些行会静默消失，需要重新核对。审批与计划审阅的点击没有可写回的文本，仍不进入历史。
