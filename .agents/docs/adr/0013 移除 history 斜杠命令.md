## 只留前缀与快捷键

`/history` 原本是会话内的斜杠入口，但它与「输入历史」快捷键和 `!` 前缀重复；它还迫使面板在挂载时关闭草稿捕获，因为斜杠 token 在桥接重新发布前仍留在草稿里。ADR 0004 记录的 `/history` 入口由本决策移除，其余桥接与 store 结构不变。

现在删除斜杠命令注册与 `commandUi` 注入，只保留快捷键命令与 `!` 前缀；`captureDraft` 字段、`requestHistory(false)` 分支与 dialog 里的草稿分支一并删除，草稿快照固定为面板打开那一刻的文本。

代价是斜杠菜单里不再能发现输入历史，用户要先知道快捷键或在输入框里打 `!`；换来的是少一个与宿主命令重名的风险点，以及一条不再需要解释的草稿特例。
