## 扁平模块与统一接口

面板原来由七条路由工厂加一个集中投影会话、工作区、命令、历史与主面板的对话框组成，路由只覆盖「输入变成行」，设置、文案、命令、槽与宿主端点各走各的入口。现在改成 `src/core` 加 `src/modules`：一个模块是声明函数，加载时执行一次，交上匹配器、挂载面、设置、文案、命令、槽、内容视图与宿主贡献；挂载面每次打开面板创建一次，行动作是模块自己的闭包，本体只保留面板级动词。

这样本体不再认识任何前缀或领域投影，新增模式只动模块目录。代价是本体的通用行、键盘、焦点与错误隔离要独立成一套稳定契约，模块内部还要把纯逻辑与 React 分开，才能继续用 node --test 直接导入。它取代 0011：内容视图不再由面板手写 kind 分支，而是模块注册渲染器。
