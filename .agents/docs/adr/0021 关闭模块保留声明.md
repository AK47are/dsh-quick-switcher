## 关闭只停运行贡献

模块开关保存的是运行期启停，不是注销：关闭时注销命令、槽与内容视图，并释放当前挂载面，文案与设置声明留在注册中心，设置页因此还能显示模块标题、说明、开关与偏好，用户也能在开启前预先配置。

没有走「关闭即整模块注销」：那会让设置页分组随开关闪烁，重新开启还要重跑声明与冲突校验。也没有只停挂载：那样快捷键与后台观察仍在运行，用户会觉得「关了却还生效」。会话模块同样可关，代价是工作区列表失去共享数据源、访问时间停止记录，设置页用模块说明与依赖警告把这两件事写清楚。

考虑过的替代方案是自动联锁关闭依赖模块，但它会改用户没点过的开关，还得决定重新开启来源模块时是否把依赖也打开，语义复杂，所以只警告不联锁。外部模块一视同仁，开关按模块 id 保存，模块暂时卸载时状态保留。
