## 入口自动注册命令

每个模块声明一条入口 `{ seed, mode?, labelKey?, aliases?, defaults? }`，本体据此注册 `quickSwitcher.mode.<module>`，标签「快速切换器：<模式名>」，别名含模块 id 与中英标题；内置入口默认不绑键，外部入口可以用 `defaults` 自带键位。按下时面板关闭就打开并播种，已在同一模式就关闭，在其他模式就原地切换。

这样新增模式不需要再手写命令。历史模块的旧命令 `quickSwitcher.history` 删除，统一到新 id；当前没有用户，不做键位迁移。命令 id 必须带点号，因为 DSH 的持久化文档只接受 `a.b` 形式的命令 id，裸 id 会让整份键位文档在下一次读取时失效。

DSH 的快捷键面板把插件命令固定收进「应用操作」，按 id 排序，不开放自定义分组；可见区分只有标签文本，因此统一加「快速切换器：」前缀。默认打开模式建立在同一入口上：未选择时取第一个入口，所选模块关闭或缺失时回退空查询，不自动改选。
