## 侧问记录落盘

侧问记录原先只存在内存里，刷新即丢，连已经标成「已中止」的记录也留不下。ADR 0009 的这条决定被推翻：记录现在镜像到浏览器的 `localStorage`，键为 `dsh-quick-switcher.ask-records.v1`，完成、出错、已中止都保存；刷新时仍在流式的记录，恢复为「已中止」并保留已经收到的答案、思考与生效模型。

保存的字段是整条记录减去待处理卡片背景，见 ADR 0030. 记录总量只由设置页的容量上限控制，不再按会话或条数另设上限：另有一个默认 1 MB、按 MB 可改的上限，按实际写入的 JSON 文本（UTF-16）计算，超限删掉最旧；设置页给出当前占用、按平均换算的条数与一个二次确认的清空入口。

代价有三处。侧问的问题与答案会写进浏览器 profile，直到用户清空或淘汰，落盘范围仍然只在本地，不写 DSH 会话日志，也不进宿主磁盘。两个 DSH 窗口各写各的完整快照，后写的那次覆盖前一次，另一个窗口的记录不会出现在这一个窗口里。刷新时正在流的记录不再能被重新接上，只能按已中止回看；这是把「不丢记录」放在「继续生成」之前的必然结果。
